## 👋 About Me

I am a **backend-focused software engineer** and MSc Software Engineering student at the **University of Tartu**.

I primarily work with **Java, Spring Boot, PostgreSQL and distributed-system patterns** to build secure APIs, event-driven services and maintainable backend architectures.

My work also includes:

- ☁️ Cloud infrastructure and containerised deployments
- 🔄 Microservices and event-driven communication
- 🔐 Authentication, authorisation and API security
- 🚀 CI/CD and infrastructure as code
- 📊 Monitoring and observability
- 🎮 Real-time WebSocket applications

I enjoy taking a project from an empty repository to a system that is structured, testable, deployed and documented.
